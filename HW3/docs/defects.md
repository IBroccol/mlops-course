# Разбор пяти намеренных дефектов

Краткий unified diff исходного `hw3-broken` и итогового кода вынесен в
[`defects-diff.md`](defects-diff.md). Здесь дополнительно разобраны симптомы,
причины и численные подтверждения.

## 1. Данные попадали в Git

**Дефект.** В `.gitignore` не было `data/`, а в `dvc.yaml` выходом split был
только `train.jsonl`. После `git add .` raw, clean, validation и test могли
оказаться в истории Git.

**Исправление.** `data/` исключён из Git, все пять артефактов объявлены outputs
DVC. Исходный снимок Wikidata также хранится через `sources/data.dvc`.
Настроен локальный remote `dvc_remote/`.

**Подтверждение.** `git ls-files data/` не возвращает файлов, автоматическая проверка видит все
пять outputs, а `dvc push` сохраняет исходный снимок и результаты в remote.

## 2. Смена версии не пересчитывала pipeline

**Дефект.** `collect` не объявлял параметры и источник зависимостями; `clean`
не зависел от `data/raw.jsonl`. Изменение `collect.version` могло оставить
артефакты предыдущей версии.

**Исправление.** В `collect` добавлены `params: [collect]`, снимок Wikidata и
код в `deps`; `data/raw.jsonl` добавлен в зависимости clean.

**Подтверждение.** Проверка версии получила разные MD5 `clean.jsonl`: v1
`723d291a` при 1 600 входных строках и v2 `39c777bc` при 3 592 строках.

## 3. Построчный split создавал утечку

**Дефект.** Случайное разбиение строк могло поместить вопрос о стране для
города в train, а сводную карточку того же QID — в test. Тестовая метрика тогда
измеряла запоминание сущности.

**Исправление.** Реализован детерминированный групповой split: четыре задачи
одного `city/QID` или `country/QID` остаются вместе. Split сам падает при любом
ненулевом показателе контаминации.

**Подтверждение.** В v2 фактические доли 0,7998/0,1003/0,1000; пересечения по
ID, тексту, группам и near-duplicate парам равны нулю.

## 4. Очистка удаляла только точные дубли

**Дефект.** Near-duplicate шаг отсутствовал: одна и та же формулировка с другой
пунктуацией переживала exact hash.

**Исправление.** После точной дедупликации применяется MinHash LSH к словным
шинглам. Clean и contamination используют одинаковый порог 0,85.

**Подтверждение.** Проверочный fixture удаляет один точный и один почти-дубль.
В полном v2 near-dup гейт дополнительно удалил одну из 3 592 записей.

## 5. Diversity предупреждал, но пропускал плохие данные

**Дефект.** Нарушения порогов только печатались, процесс завершался кодом 0.
Вырожденный набор из 1 200 шаблонных строк проходил дальше.

**Исправление.** Каждое нарушение печатается отдельной строкой с фактом и
порогом, затем стадия поднимает `DiversityError`.

**Подтверждение.** Негативный тест роняет вырожденный набор и называет четыре
нарушенных порога. v2 проходит: 3 591 пример, 5 системных промптов, 898 групп,
доля крупнейшей группы 0,11%, `p90/p10 = 2,98`, повторных ответов 0%.
