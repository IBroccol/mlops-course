# Географический датасет с версионированием DVC

Проект формирует русскоязычный chat-датасет для извлечения проверяемых фактов
о городах и странах из структурированных карточек Wikidata. Ответ строится
только по переданной карточке и явно учитывает дату снимка источника.

## Данные

Исходные записи получены из Wikidata и зафиксированы в DVC. Структурированные
данные Wikidata распространяются по лицензии CC0 1.0. Обычный запуск пайплайна
не обращается к сети и использует сохранённый снимок.

Каждый пример имеет поля `id`, `topic` и `messages`. В `messages` находятся три
реплики в порядке `system`, `user`, `assistant`. Для каждой сущности создаются
четыре типа заданий: местоположение, численные характеристики, координаты или
столица и краткая сводка.

## Версии

| Показатель | v1 | v2 |
|---|---:|---:|
| Сущности | 400 городов | 700 городов и 198 стран |
| Сырые примеры | 1 600 | 3 592 |
| Примеры после очистки | 1 600 | 3 591 |
| Train | 1 280 | 2 872 |
| Validation | 160 | 360 |
| Test | 160 | 359 |

Все задания одной сущности остаются в одном сплите. Для v2 пересечения между
train и test по идентификаторам, нормализованному тексту, группам и
near-duplicate парам равны нулю.

## Пайплайн

```text
collect → clean → diversity → split
```

- `collect` создаёт примеры из выбранной версии снимка;
- `clean` валидирует схему, маскирует ПДн и удаляет дубли;
- `diversity` проверяет размер и разнообразие набора;
- `split` выполняет детерминированное групповое разбиение и проверяет
  контаминацию.

Параметры находятся в `params.yaml`, зависимости и артефакты стадий — в
`dvc.yaml`. Данные исключены из Git и хранятся в DVC.

## Запуск

```bash
uv sync
make repro
make check
```

Дополнительные команды:

```bash
make v1             # собрать первую версию
make v2             # собрать вторую версию
make diff           # сравнить метрики двух коммитов
make diversity      # проверить разнообразие
make contamination  # проверить train/test
```

Описание источника находится в `sources/SOURCE.md`, паспорт данных — в
`docs/datasheet.md`, разбор исправленных дефектов — в `docs/defects.md`,
а их изменения в формате unified diff — в `docs/defects-diff.md`.
