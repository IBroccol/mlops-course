## Дефекты из hw1-broken

### 1. Имя модели в коде

В `model.py`, `generate.py`, `bench.py` стояло `"Qwen/Qwen3-0.6B"`. Смена `params.yaml` ничего не меняла. Убрал — имя только из конфига.

### 2. Зависимости без версий

В `pyproject.toml` было `torch`, `transformers` без границ, без `uv.lock`. Добавил `>=` и `uv sync`.

### 3. bench.py мешал загрузку и генерацию

Один таймер на всё, `load_time_sec` всегда 0. Разделил: отдельный load, warmup, медиана скорости только по генерации.

### 4. Нет воспроизводимости

`temperature: 0.7`, seed не вызывался. Поставил `0.0` и `set_seed()` перед генерацией.
